# 设计参考记录

## 参考对象

- 线上作品集：<https://wodniack.dev>
- 公开源码：<https://github.com/AntoineW/AW-2025-Portfolio>

参考项目采用 Astro、GSAP、Lenis 与 Sass。公开仓库使用 CC BY-NC 4.0 许可，并明确说明它不是可直接换皮商用的模板。本项目只研究其设计原则、叙事节奏和创意开发方法，不复制代码或视觉资产。

## 借鉴的设计原则

1. **排版承担视觉主体**：使用超大字号、紧凑字距、小型编号与信息栏建立秩序。
2. **连续叙事**：首页不是一组彼此割裂的卡片，而是从身份、文字、作品、媒介转化、个人经历走到联系入口。
3. **少量高强度动效**：动画服务于进入、停留和离场，不让所有元素长期漂浮。
4. **项目文字与媒体联动**：项目名称是主要导航，媒体舞台在当前项目改变时更新。
5. **技术实现保持静态与轻量**：Astro 输出静态文件，Lenis 负责桌面平滑滚动，GSAP/ScrollTrigger 负责关键时间轴。

## 明确没有复制的内容

- 没有复制参考站的源码、组件层次、DOM 结构或 SCSS。
- 没有使用其红黑配色、波浪生成视觉、二进制装饰、项目随机编号和个人履历文案。
- 没有复用其图片、视频、字体、Logo、图标或任何作品素材。
- 没有照搬单页履历结构。Denpa 站额外包含小说阅读、画作画廊、影像和游戏详情。
- 没有使用参考项目的独特 Work 作品序列和个人照片档案表达。

## Denpa 的原创转化

Denpa 的主线是“媒介转化”：

```text
一句文字
→ 一幅画面
→ 一段运动影像
→ 一个可运行原型
```

因此首页从巨型 DENPA 身份开始，转入 Warm Paper 小说引文，再进入文字列表与媒体舞台，随后给出小说、画作、影像、游戏四个章节，最后使用重叠的媒介层表现创作过程。颜色系统改为 Carbon Black、Warm Paper、Warm White 和少量 Lime。

## 首页滚动方案

### Hero

- 整段高度约 150vh。
- 桌面端使用 ScrollTrigger pin 固定约一个视口。
- scrub 时间轴让大标题缓慢上移，媒体轻微放大，说明文字稍微离场。
- 首次进入使用约 1 秒的 Lime 遮罩揭示。

### 小说引文

- 背景从深色切换到 Warm Paper。
- 每行文字用 `clip-path` 和纵向位移逐行揭示。
- 留白与停顿比动画数量更重要。

### 精选作品

- 桌面端左侧为项目文字列表，右侧媒体舞台使用 CSS sticky。
- 鼠标悬停、键盘聚焦和滚动进入项目时触发相同切换。
- 媒体切换使用覆盖和位移结构，不把整段做成自动轮播。
- 移动端变成自然的“项目—媒体—简介”纵向序列，不依赖 hover。

### 四个创作章节

- 使用占满横向空间的巨型标题行，不使用普通圆角卡片。
- 进入章节时仅使用约 190ms 的 Lime 遮罩闪切。

### 创作过程

- 三个阶段是彼此覆盖的 sticky 纸页，不是并排信息卡。
- 后一层出现时，前一层仍留下边缘和位置痕迹。

### 页面尾部

- About、服务和联系方式恢复稳定的编辑排版。
- 动效逐渐减弱，让阅读和联系方式成为主体。

## 桌面端与移动端

### 桌面端

- Lenis 平滑滚动与 ScrollTrigger 同步。
- Hero 使用 pin + scrub。
- 精选媒体使用 sticky；列表的 hover、focus 和滚动都可激活媒体。
- 创作过程使用 sticky 叠层。
- 全站没有 WebGL、Canvas 核心内容和连续粒子动画。

### 移动端

- 关闭 Hero pin 和 scrub。
- 取消复杂横向滚动。
- 所有内容回到自然纵向布局。
- 创作过程叠层改为普通顺序排列。
- 不依赖 hover，所有入口可直接点击和键盘访问。
- 320px 宽度仍保留最小 14px 页面边距。

## Reduced Motion

当系统启用 `prefers-reduced-motion: reduce`：

- 不初始化 Lenis。
- 不创建 pin、scrub 和遮罩时间轴。
- 入口遮罩直接隐藏。
- 所有内容直接显示，CSS 动画和过渡缩短至接近 0。
- 阅读、导航、画廊和视频控制仍可完整使用。
